# せんろを つなごう！

電車が大好きな幼児向けの、線路をつなぐパズルです。ブラウザで開くだけで遊べます。

**あそぶ：https://ryu4ya-cmd.github.io/senro/**

iPhone・iPad の Safari で開いて「共有 → ホーム画面に追加」、Android の Chrome ならメニューの「ホーム画面に追加」をすると、アプリのように全画面で遊べます。

電車は、阪急電車（マルーンの車体とアイボリーの屋根）と、山手線（銀色の車体と黄緑の帯）から選べます。

## あそびかた

1. スタートの駅（みどりの旗）から、ゴールの駅（ピンクの旗）まで、空いているマス（点線の四角）に線路を置いてつなげます。
2. 下に並んだ線路を1つ さわって選び、置きたいマスを さわると置けます。線路をそのまま置きたいマスまで引っぱっても置けます。
3. 置いた線路を さわると外せます。
4. 「しゅっぱつ！」を押すと電車が走ります。つながっていれば、ゴールで動物のお客さんが よろこびます。
5. つながっていないときも電車は走り出し、線路が切れているところの手前で止まります。そのマスが光り、「ここを つないでみよう」と教えてくれます。

- **もどす**：ひとつ前に戻します。
- **やりなおす**：置いた線路をぜんぶ外します。
- **ヒント**：1回目は置く場所が光り、2回目は置く線路の形がうすく出ます。

制限時間や失敗はありません。何度でもやり直せます。

## ステージ

全10ステージです。

- 1〜3：3×3マス。まっすぐ・カーブを1〜2か所 うめます（ステージ1は手の絵で操作を案内します）。
- 4〜6：4×4マス。木や池をよけるルートもあります。5と6は、まぎらわしい線路が1つまざります。
- 7・8：5×5マス。4〜5か所 うめます。まぎらわしい線路が2つまざります。
- 9・10：線路をぐるっと一周させるステージです。電車が駅を出て一周し、同じ駅に戻るとクリアです。

クリアしたステージには星がつきます（その端末のブラウザの中だけに保存されます）。

## 音と声

- **BGM**：オルゴールふうの曲を、ブラウザの中でその場で作っています。声が流れる間は小さくなります。
- **効果音**：線路を置く音・汽笛・走る音・到着の音も、ブラウザの中で作っています。
- **声**：「しゅっぱつ しんこう！」「じょうずに できたね！」などは、もじもじの もり・ふみきり カンカン で作った声（`voice/`）を使っています。
  Style-Bert-VITS2 モデル「小春音アミ」で作った声で、もとは [あみたろの声素材工房](https://amitaro.net/) の声です（モデルの作者：litagin さん。[利用規約](https://huggingface.co/litagin/sbv2_koharune_ami)）。
  その声がないセリフや、声のファイルがない場所（claude.ai の公開ページなど）では、端末の読み上げ機能を使います。読み上げが使えない端末でも、絵と表示だけで遊べます。
- 右上のスピーカーのボタンで、BGM・効果音・声をまとめて消せます。

## 古いタブレットで遊ぶとき

もじもじの もり・ふみきり カンカン と同じく、古いブラウザでも動くようにしています（目安は Chrome 49 以降、iPad は Safari 10 以降）。
うまく動かないときは、画面の上に案内が出ます。

## ファイル

- `src/game.html`：ゲーム本体。直すときはこのファイルを編集します（claude.ai の公開ページもこのファイル）。
- `tools/build.js`：`src/game.html` から `index.html` を作ります。古いブラウザでも動くように、スクリプトを Babel で変換し、CSS の `clamp()` などに かわりの値を書き足します。
  はじめの1回だけ `npm install`、そのあとは直すたびに `npm run build`。
- `index.html`：公開用のページ（自動で作られるので、直接は編集しません）。
- `voice/`：声の mp3 と、セリフの名前 → ファイル名の表 `index.json`。
- `icons/`、`manifest.webmanifest`：ホーム画面に追加したときのアイコンと設定。アイコンの元の絵は `icons/icon.svg`、png は `tools/make_icons.js`（Playwright を使います）で作ります。
